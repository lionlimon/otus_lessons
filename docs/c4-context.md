# C4 — Context (C1)

Система как единое целое, её пользователи и внешнее окружение. Контекст системы — см. [README](../README.md), драйверы — [Utility Tree](utility-tree.md), компромиссы — [Trade-offs](tradeoffs.md), контейнеры — [C4 Container](c4-container.md).

```mermaid
graph TB
    agent["👤 Агент поддержки<br/><i>обрабатывает тикеты</i>"]
    super["👤 Супервайзор<br/><i>контролирует работу, SLA</i>"]
    admin["👤 Администратор<br/><i>роли, маршрутизация, интеграции</i>"]

    system["🎯 Enterprise-админка саппорта<br/><b>Единая очередь тикетов с агрегацией<br/>контекста, ролями, аудитом</b>"]

    orders["📦 Сервис заказов<br/><i>внешний, др. команда</i>"]
    flights["✈️ Сервис рейсов<br/><i>внешний, др. команда</i>"]
    pax["🧳 Сервис пассажиров/услуг<br/><i>внешний, др. команда</i>"]
    idp["🔑 Провайдер идентификации<br/><i>SSO/OIDC</i>"]
    notify["📨 Каналы доставки<br/><i>Slack / email</i>"]

    agent --> system
    super --> system
    admin --> system

    system -->|"читает контекст"| orders
    system -->|"читает контекст"| flights
    system -->|"читает контекст"| pax
    system -->|"аутентификация"| idp
    system -->|"шлёт алерты"| notify
```

**Границы системы.** Внутри — рабочее место саппорта и всё, что управляет тикетами. Снаружи — продуктовые сервисы других команд (заказы, рейсы, пассажиры): система только **читает** из них контекст, но не владеет этими данными.
